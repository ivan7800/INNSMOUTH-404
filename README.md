# INNSMOUTH-404

La herencia de las profundidades — survival horror narrativo de horror cósmico en pixel art.

Versión: **1.0.0-rc.7.1** (candidata a publicación).

Campaña de ocho capítulos, tres finales, investigación, exploración y supervivencia. Proyecto independiente de ASHEN-VEIL-404.

## Ejecución

Abre `index.html` desde un servidor HTTP estático o `JUGAR-SIN-INSTALAR.html` directamente en un navegador compatible. GitHub Pages puede servir el proyecto desde la raíz de `main`.

La validación física, el balance mediante partidas humanas y WebGL experimental siguen pendientes. No se declara una versión estable libre de errores.
